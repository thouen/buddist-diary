# 学佛日记 2.6

一部记录每日念佛、诵经、持咒、仪轨与修行日记的手机应用。单文件网页应用（PWA），针对安卓手机竖屏优化，可「添加到主屏幕」当作原生 App 使用，离线可用。

> 本版（2.6）：月历上同一天的斋日**只画一颗蓝点**，「斋日」统一改称**斋戒日**；年份选择放开到 **1900 – 2100**；「我的重要日」改名**我的纪念日**、排在节气与功课之间；功课新增**可选月目标**（月目标与总目标都不画进度条，只有日目标有）；「日记功能」改名**记录日记**；「今」按钮重画得更精致。
>
> **本轮修订（未发版）**：纪念日标记统一为**青碧色**，**年份**与**是否每年重复**拆成两项分别设置，年份选择改为从当年开始翻；设了月目标后**按月统计会给达标月份打 ✓**，按年不显示目标与达标；非当天的补录按钮改**深墨棕实底白字**；详情页「按年／按月／按日」分段不再用功课红；斋戒日顺序的文档描述与代码对齐。历史版本的改动见 [CHANGELOG.md](CHANGELOG.md)。

## 一、功能

**首页**
- 顶部为整月日历，同时显示公历与农历。**佛教节日金色**、**斋戒日蓝色**、**传统节日黄色**、**二十四节气绿色**、**纪念日青色**、**当天有功课红色**；日期下方的小点自上而下排列，顺序与图例一致
- 月历下方图例共六项，自左至右：**佛教节日 · 斋戒日 · 传统节日 · 节气 · 纪念日 · 功课**。朔望、观音斋、六斋、十斋、月斋都归到「斋戒日」一项，**同一天命中多类也只画一颗蓝点**
- 月历标题里的**年份**与**月份**都可点开：年份给出 **1900 – 2100** 整段（列表从近到远倒序，打开就停在当年首行，不用从 1900 年一路往上翻），月份给出 12 个，点一下直接跳过去，不用逐月翻
- 斋戒日改为**多选**，五种各自独立开关，可任意组合；不论命中几类，日历上**只显示一颗蓝色小点**，日期条仍逐类列出：
  - **朔望日**：农历初一、十五
  - **观音斋**：农历每月固定日，全年 **22 日**（正月初八、二月初七、初九、十九、三月初三、初六、十三、四月廿二、五月初三、十七、六月十六、十八、十九、廿三、七月十三、八月十六、九月十九、廿三、十月初二、冬月十九、廿四、腊月廿五），默认关闭
  - **六斋日**：初八、十四、十五、廿三、廿九、三十（小月无三十，以廿八、廿九补足）
  - **十斋日**：初一、初八、十四、十五、十八、廿三、廿四、廿八、廿九、三十（小月以廿七至廿九补足），**默认开启**
  - **月斋（三长斋月）**：农历**正月、五月、九月整月持斋**，默认关闭
  - 同日命中多类时，日期条的标签次序固定为：朔望日 → 观音斋 → 六斋日 → 十斋日 → 月斋
- 传统节日含**北方小年（腊月廿三）**与**南方小年（腊月廿四）**，两者分列，不再合并为一个「小年」
- 支持**自定义农历 / 公历的纪念日**（生日、受戒日、纪念日等），日历上以**青点与青色名称**标出，日期条显示青色标签；**年份**和**是否每年重复**是两项独立设置：年份可留空、也可记下是哪一年（设为「每年重复」时年份只作记录），设为「只此一年」就只在选中的年份出现一次
- 选中日期下方的日信息分**三行**：第一行「佛历年份 · 公历年月日」（如「佛历 2569 年　2026年11月10日」），第二行「农历月日 · 星期 · 相对日」，第三行是当天的标签（佛教节日、斋戒日、传统节日、节气、纪念日）。公历年月日**带完整年份**；窄屏（≤345px）两行整体降一档字号，320 宽也不会被截断
- 相对日按距今天的远近显示：**前天 / 昨天 / 今天 / 明天 / 后天**，再远则是 **N 天前 / N 天后**（如「9天前」「5天后」）
- 当天的公历日期与「今天」二字都是**金色**；其他日期为墨色
- 日期信息条左右两侧各有一个 `‹` `›` 箭头：点按即切换到前一天／后一天，与在日信息区左右滑动等效
- **不在今天时**，日信息右侧会出现一个圆形小按钮**「今」**，外面绕着一圈顺时针箭头（细圆环在右上留缺口、箭头指顺时针方向），一眼看出是「回到今天」：靠右，垂直居中于上面两行；在首页点它回到今天的记录页，在功课详情页点它则停在这项功课、切到今天的详情；点按钮不会误触日期选择器
- 功课分为 **念佛 · 诵经 · 持咒 · 仪轨 · 日记** 五个标签页，内容可自行增删改。切到非当天时，标签页的文字与下划线仍用功课红，「＋」与 `+1` 等按钮改为**深墨棕实底白字**（补录态，与四个米白数字按钮拉开主次）；未来日期仍全部置灰不可点
- 每项功课提供 `+1` `+10` `+100` `+1000` `+` 五个按钮：末位 `+` 按该项的默认增量增加（默认：念佛持咒 100，诵经仪轨 1）；不单设减号，减少统一走「长按 +」
- 长按 `+` 弹出「调整今日数量」：可在**减少／增加／设为**之间切换——前两者填多少就加减多少（减到 0 为止，不会出现负数），**设为**是直接把当天数量改成输入值（填 0 即清零）；长按 `+10` `+100` `+1000` 则是持续连加。选中的不是今天时，标题与副标题改称**「调整此日数量」「此日 N 遍」**（副标题带单位）；切到「设为」时标签写「今日总量／此日总量」
- 点击计数数字可直接手动输入当天数量
- **只有标题行与「本月（此月）/ 累计」统计行能点进详情**；点加减按钮、计数数字、日目标进度条、按钮区空白都不会误跳。计数按钮完全独立，连点 `+1` 也只会加数
- 「显示月累计」与「显示总累计」都默认开启：每项功课在进度条下方显示一行「本月 N　累计 M」，**当月合计在左、累计总数在右**；设了月目标 / 总目标就分别显示「本月 N / 月目标」「累计 M / 总目标」，随加减实时更新；两项都可在设置里单独关掉。选中日期不在本月时，左边写作**「此月 N」**（说的仍是选中日期所在的那个月）；该月合计达到月目标时，月目标后面补一个 **✓**，与日目标达成的写法一致
- 前四个标签页的内容区顶部可选显示**日分类汇总**，一行列出选中日期记过的每一项，标题写作**「今日汇总」**（不在今天时为**「此日汇总」**），如「今日汇总 南无阿弥陀佛×100；南无地藏王菩萨×1000。」；默认关闭，可在设置里打开
- 向下滚动时，**日期信息与五个标签页一起固定在顶部**（月历滚走）
- 任意功课可在「功课设置」中填写**每日目标 / 月目标 / 总目标**（三项都写「可选，留空则不设」）：只有**日目标**画细进度条（达成后数字与进度条转为金色）；月目标与总目标只作数字对照，不画进度条
- 首页分三个区域，左右滑动各司其职：
  - **月历区**：右拖上一月，左拖下一月（不改选中日期）
  - **日信息区**：右拖前一天，左拖后一天
  - **内容区**：在五个标签页间左右切换；汇总视图下不响应左右滑动
- 点日期即选中该日；点日期信息区域可调出系统日期选择器
- **未来的日期只能看，不能记**：选到明天或更晚，加减按钮与「＋」全部置灰，点计数也不会弹窗；**日记同样不能写**——正文变成只读，工具条整条收起只留一句「未来的日期还不能写日记」，地点 / 天气也点不动；数据层一并拒绝写入。日历照常可以翻到未来查看节日与农历

**详情页**
- 点功课名称进入，自上而下三段：**日信息**（公历、星期、农历、佛历与当天标签）→ **当日计数与操作按钮** → **按日／按月／按年统计**
- 计数区显示**当日数 → 日进度条（右侧 n / 目标）→ 月合计与月目标（左）／累计与总目标（右）**；「显示月累计」开关只管左边那半，右边的「累计」在详情页**始终显示**
- 计数大数字可点，直接改选中日期的数量。选中的是今天时，计数区标题写「今日念佛」，月合计写「本月」；补录别的日子时两者都改称**「此日念佛」「此月」**，无障碍标签同步为「修改此日数量」
- 月合计与累计两行**只写数字、不再重复单位**（单位以计数大数字为准），月合计达到月目标时同样补一个 ✓
- 计数区上排是一个整行大按钮 `+1`，下排依次为 `+10` `+100` `+1000` `+`（`+` 按默认增量，长按弹窗可增减或直接设定当天总量；长按 `+10` 以上则连加）
- 详情页的日信息卡片同样在左右两侧带 `‹` `›` 箭头，点按切换前后日
- 三种统计表格：**按日**（一周 7 列的整月表格）／**按月**（12 个月的表格）／**按年**（最近 6 年，3 列 2 行）；每格显示当日／当月／当年的累计数，底色按数量分三档加深；表格顶部的 `‹` `›` 用来换期，右侧的**「回到本月／回到今年／回到近年」**一键跳回当期
- 顶部显示合计、记录天数（月数、年数）、日均、最高值；按日表格的合计行在当月写「本月合计」，翻到别的月份写「此月合计」；**按日**设了每日目标显示「目标 X · 达标 N 天」，**按月**设了月目标显示「月目标 X · 达标 N 个月」并给所有月合计达标的格子打金色 ✓；**按年视图不显示任何目标／达标字样，也不打勾**（目标体系只有日 / 月 / 总三种，总目标只作累计数字对照）
- 详情页左右拖动：在**统计区**滑动切换按日／按月／按年，在**日信息或计数区**滑动切换前后日的功课详情
- 右上角有编辑按钮，可改这项功课的名称、单位、增量、日目标、月目标与总目标，底部还有**「在功课列表中显示」开关**——关掉只是藏起来，计数与目标都保留，随时能再打开；**内置功课的编辑弹窗不给删除按钮**，只留一句「内置功课只能隐藏，不能删除」，想让它消失就关掉这个开关

**日记（纯文本）**
- 顶部可**选填天气**：常见天气排在前面，三列图标一屏选完，也可以自己写（如「梅雨」，最多 8 字）；旁边是**地点**
- 地点有三条路：**常用地点**一键选、**按省 / 市挑**、**输入临时地点**。**应用不读取定位、也不联网反查地名**
- 常用地点每一行右侧有铅笔按钮，可直接改名、改省市、设为默认或删除
- 可指定一个常用地点为**默认地点**，设置里「始终使用最近一次地点」默认开启
- **自动填地点只在必要时发生**：切到日记页不会凭空填；只有**当天**、且你**真的点进了日记正文**之后，才补上「最近一次地点」或「默认地点」。切到昨天／明天写日记不会自动填；手动清除地点后，当天也不再自动补
- 日记就是**一整篇纯文本**：不分条、不编号、不带序号，换行只是普通的换行；正文可以随意选中、复制，粘到别处就是一篇普通文字
- 工具条从左到右六个按钮：**撤回 · 重做 · 无序列表 · 上方插入新行 · 下方插入新行 · 时间**
  - **撤回 / 重做**：按文本快照回退，一次连续输入算一步（停手 0.4 秒记一步），最多 50 步；插入时间、圆点、插入新行都可撤回；切换日期后历史清空（内容本身不受影响）
  - **无序列表**：在光标所在行的行首插入「• 」（圆点 + 半角空格），再点一次则移除。圆点是**文本字符**，复制时会一起带走
  - **上方 / 下方插入新行**：在光标所在行的上方或下方加一个空行，光标随即落到新行；图标是「加号 + 一条新行」，加号在上即插在上方
  - **时间**：只在光标处插入形如 `[05:01]` 的文字，不换行、不改写已有内容
- **整体复制**：元信息行右侧有**复制全文**按钮，一次复制整篇；也可以直接在正文里选中复制。复制出来的文字不带任何序号，行与行之间就是一个换行
- 元信息行右侧显示**字数**（不算空白），旁边就是复制按钮
- **日记可以整体关掉**：设置 → 日记 → 「记录日记」，关掉后首页不再有日记标签页，已写的内容仍留在数据里；此时设置页会**隐藏**「总览显示日记」这一行，它的值**原样保留**（下次重新打开记录日记时按原值恢复）。两个开关**任一为关**，汇总卡片里都不显示日记内容
- 只保存文字：没有插图、拍照，也没有图片按钮与占位。旧版本按块保存的日记，打开时会**自动折成一段纯文本**（图片块直接丢弃，文字不丢）

**汇总视图**
- 首页右上第一个按钮切换：记录视图 ⇄ 汇总视图
- 上半部分与记录视图完全一致：整月日历与日期条始终保留，只有下半部分在「五个标签页」与「按日滚动的汇总」之间切换
- 汇总内容顶部显示**连续功课天数**（仅前四类功课有计数才算），右侧上行为起始日期「自 X 月 X 日起」，下行为「累计 N 天记录功课」；关掉「记录日记」或「总览显示日记」后，只有日记的那一天不再占一张卡片，卡片里也不显示日记内容
- 汇总按日期由近及远排列；每张卡片头部附当天地点与天气（可在设置里一键隐藏），上方面板显示当天有计数的功课，下方面板显示当天日记（最多 3 行）
- 在汇总视图里拖动日历翻月，会自动滚到该月最近的一条记录
- 点卡片即切回五个标签页的模式并跳到那一天；点「功课」面板落在有记录的那一类，点「日记」面板落在日记页

**其他**
- 右上菜单：功课设置、节日一览、我的纪念日、回到今天、设置
- **节日一览**把佛教节日与传统节日合在一页：顶部分段（佛教节日／传统节日）可直接点，也可以**在列表上左右划动**切换；两页都可翻年查看
- 功课设置支持增删改、**置顶**、上移、下移、**隐藏**、恢复内置功课；置顶只在本分类内生效；每行副标题第一行是「单位 · 增量 N」，设了日目标再补「· 日目标 X」，设了月目标或总目标则**另起一行**写「月目标 M · 总目标 T」
- 删除自定义功课时在**应用内**弹一次确认（「删除这项功课？」→ 取消 / 删除），不用系统弹窗；**内置功课不能删除**，只能隐藏——编辑弹窗里不给删除按钮、只留一句提示，就算点到删除入口也会被拦下
- **隐藏**：每行最右边的眼睛图标（最左是名字，往右依次是眼睛、置顶、上移、下移、编辑），点一下收起来（主页列表不再显示，统计与目标一并隐去），再点一下放出来；已隐藏的行文字变淡、图标变为划线眼睛，标题处显示「隐藏 N 项」。隐藏只影响显示，已记的数量不会丢
- 我的纪念日：添加／编辑／删除自定义纪念日，可选农历或公历，并可分别设置**年份**（可留空，下拉按「近年从当年开始 → 更早 → 未来」分组）与**重复方式**（每年重复／只此一年）；列表按最近到来排序并显示还有多少天（只此一年的标注「仅 X 年」）
- 设置项按分区自上而下：**历法**（佛历基准 +543／+544）、**斋戒日（可多选）**（朔望日 / 观音斋 / 六斋日 / 十斋日 / 月斋，按此顺序）、**日历**（佛教节日 / 传统节日 / 二十四节气 / 我的纪念日 / 总览显示地点与天气）、**地点**（常用地点 / 始终使用最近一次地点）、**功课列表**（显示总累计 · 显示月累计 · 显示日分类汇总）、**日记**（记录日记 / 总览显示日记）；其中「显示日分类汇总」的说明是「在念佛 / 诵经 / 持咒 / 仪轨 顶部列出此日功课记录汇总」
- 数据导出／导入（JSON，纯文本）、数据概况、清空数据
- 五处二次确认（删功课、删常用地点、删纪念日、导入覆盖、清空数据）都在**应用内**弹窗里做，不用系统弹窗；从编辑弹窗里点删除再按「取消」，会回到原来的编辑弹窗，刚填的内容还在
- 数据概况里「功课总计数」按 **念佛 / 诵经 / 持咒 / 仪轨 / 日记** 五类分别统计（念佛、持咒以遍计，诵经以部计，仪轨以遍计，日记以篇计），另附记录天数、功课条目与最早记录
- 设置页底部为回向偈：「学佛功德殊胜行，无边胜福皆回向／普愿沉溺诸众生，速往无量光佛刹」

## 三、在安卓手机上使用

### 方式一：部署后安装为 App（推荐）

1. 把本目录下的所有文件上传到任意支持 HTTPS 的静态托管（GitHub Pages、Vercel、Netlify、对象存储、自己的服务器均可）
2. 手机用 Chrome 打开该网址
3. 右上角菜单 → **添加到主屏幕 / 安装应用**
4. 桌面会出现图标，点开后全屏运行，与原生 App 无异；断网也能用

> 必须通过 http(s) 访问才能启用离线缓存与安装。直接双击 `index.html` 以 `file://` 打开也能使用全部功能，但无法安装和离线缓存。

### 方式二：直接安装 APK

- 文件：`学佛日记-2.6.apk`，约 373 KB，支持 **Android 7.0 及以上**
- 内嵌页面即本仓库的 `index.html`（2.6），打包时校验过逐字节一致（比对方法见「发布检查清单」）；**2.6 修订（一）（二）之后 `index.html` 又改过，APK 内仍是上一轮的页面**，下次发版要重新打包并复核
- 传到手机后点击安装，需允许「安装未知来源应用」；首次打开若提示风险，选择「仍要安装」即可
- 内嵌页面由 WebView 以 `https://appassets.local` 提供，`localStorage` 能长期保存，重启应用数据不丢
- 返回键：先关弹窗 / 菜单 / 日期层，再退二级页面（详情、设置等），回到首页再按一次才退出
- 「导出备份」会直接把 JSON 写进手机「下载」目录（Android 10 及以上）
- APK 与浏览器版数据互不相通；卸载应用会一并清除数据，卸载前请先导出备份
- 安装包为自签名（非应用商店分发），以后换新版本时直接覆盖安装即可，数据保留

**关于权限（如实说明）**：2.2 起已从 `AndroidManifest.xml` 删掉 `INTERNET`、`ACCESS_FINE_LOCATION`、`ACCESS_COARSE_LOCATION`、`READ_MEDIA_IMAGES`、`READ_MEDIA_VISUAL_USER_SELECTED`、`READ_EXTERNAL_STORAGE`，`aapt2 dump permissions` 现在**一个权限都没有**。网页一侧也没有任何网络请求与定位调用，导出走系统「下载」、导入走系统文件选择器，都不需要权限。

**关于签名**：2.0 / 2.2 / 2.3 / 2.4 / 2.5 / 2.6 使用同一张证书（SHA-256 `9ad2a321…1bcc14`），可直接覆盖安装到已装 2.0 的手机，数据保留。签名私钥 `xuefo.keystore` 不在本仓库，请另行备份；若哪天换了新签名，就无法覆盖安装，必须先导出备份 → 卸载旧版 → 装新版 → 导入备份。

> 若要自己重新打包：当前 APK 是**手写 WebView 外壳**，与 [PWABuilder](https://www.pwabuilder.com/)、Bubblewrap、Capacitor 这类工具生成的容器不等价——那些工具只适用于纯浏览器 PWA 路线，做不出同样的文件保存、相机、返回键行为。仓库里也可以直接把 `index.html`、`manifest.webmanifest`、`icons/` 当静态资源自行打包。WebView 内 Service Worker 不生效属正常现象，不影响功能。

## 四、数据与隐私

- 功课、日记文字、天气与地点、目标数量、自定义纪念日全部保存在浏览器 `localStorage`（键名 `xuefo.diary.v1`）
- 省市列表内置在 `index.html` 中，选省市不需要联网
- **应用不发起任何网络请求**：没有定位、没有地名反查、没有统计上报。代码里 `fetch(`、`navigator.geolocation`、Nominatim 均为 0 处
- 旧版本可能存过图片（IndexedDB 库 `xuefo-img`，或日记记录里的 `b.x` 字段）。2.1 起不再读取、显示或导出这些图片，但**不会主动删除你本机已有的数据**
- **数据读坏时的保护**：万一本机数据解析失败，应用会把原始字符串原样另存为 `xuefo.diary.broken.<时间戳>`，弹出提示，并**暂停写入**，避免新数据覆盖原件；此时可到「设置 → 导入备份」恢复，或到「设置 → 清空全部数据」重新开始
- **导入的备份会先体检**：只接受结构正确的数据，计数会收口为非负整数、日记块只留文字、超长字段截断、未知字段丢弃；格式不对会明确提示「未导入任何数据」，不会导入半截
- 「清空全部数据」会一并删掉所有 `xuefo.` 开头的本地键与旧图片库，不留残余
- 建议定期用「设置 → 导出备份」保存一份 JSON 到网盘；卸载应用或清除浏览器数据会一并清除本机记录

## 五、历法口径

- 农历、节气由 `lunar-javascript`（6tail）推算，覆盖 1900–2100 年
- 佛历采用「公历年 + 基准」，默认 +543（佛历元年为公元前 544 年，与泰国历及汉传常用说法一致），可在设置中改为 +544
- 朔望日：农历初一（朔）、十五（望）
- 六斋日：农历初八、十四、十五、廿三、廿九、三十；**小月无三十，以廿八、廿九代之**，仍为六日
- 十斋日：大月为初一、初八、十四、十五、十八、廿三、廿四、廿八、廿九、三十；小月无三十，则为初一、初八、十四、十五、十八、廿三、廿四、**廿七**、廿八、廿九，十日不缺
- 观音斋：按上表 22 个农历日期标记，闰月不计
- 月斋（三长斋月）：农历**正月、五月、九月**的每一天都算斋日，与其他斋日互不影响，可同时出现
- 佛教节日都按农历；表里定在**三十**的（如地藏菩萨圣诞七月三十、药师琉璃光如来圣诞九月三十），遇小月（只有廿九）就落在该月最后一天，不会漏掉
- 五类斋日是**多选**，可同时开启；同一天命中几类，日历上也只标一颗蓝点，日期条仍按「朔望日 → 观音斋 → 六斋日 → 十斋日 → 月斋」逐类列出
- 「有功课」只认前四类功课的计数；日记不参与日历标记与连续天数，但仍完整保留在汇总列表里
- 闰月按当月实际天数计算，不另作增减
- 佛教节日按农历月日计算，闰月不计。诸佛菩萨纪念日各寺所用历法略有出入，此表依通行之说；如需增改，编辑 `index.html` 中的 `FESTIVALS` 常量即可

## 六、发布检查清单

每次发布新的 `index.html`，逐条确认：

- [ ] **`sw.js` 顶部的 `CACHE` 版本号已 +1**（如 `xuefo-diary-v25` → `v26`）。不改的话，老用户会一直读到缓存里的旧页面
- [ ] `icons/` 里的三张图标与当前设计一致（192 / 512 / maskable-512）
- [ ] 若重新打包 APK，确认 APK 内 `assets/index.html` 与工作区的 `index.html` **内容一致**（注意换行符：工作区文件是 LF，手工另存时别变成 CRLF）；比对方法：`unzip -p 学佛日记-x.y.apk assets/index.html | sha256sum` 与 `sha256sum index.html`
- [ ] 改 `AndroidManifest.xml` 的 `versionCode`（每次 +1）与 `versionName`，再打包
- [ ] `apksigner verify --print-certs` 确认证书仍是 `9ad2a321…1bcc14`，否则老用户无法覆盖安装
- [ ] 发版前自测：首页日历、五个标签页、日记撤回/重做/圆点、详情页统计、设置页开关、导出与导入各走一遍，确认不是白屏
- [ ] 更新 `index.html` 里「设置 → 关于」的版本号，并在 `CHANGELOG.md` 记一笔
- [ ] 导出一份备份做回归样本，导入后累计数应立即刷新


`index.html` 为完全自包含的单文件，可单独拷贝使用。
