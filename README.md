# 学佛日记

一部记录每日念佛、诵经、持咒、仪轨与修行日记的手机应用。单文件网页应用（PWA），针对安卓手机竖屏优化，可「添加到主屏幕」当作原生 App 使用，离线可用。

---

## 一、功能

**首页**
- 顶部为整月日历，同时显示公历与农历；**佛教节日以金色**、**二十四节气以绿色**标出（日期数字与名称同色），两者在日期下方各有一个小点
- 月历标题里的**年份**与**月份**都可点开：年份给出前后各 12 年共 24 个，月份给出 12 个，点一下直接跳过去，不用逐月翻
- **当天有做功课**：日期数字**右上角一个金色小点**；**佛教节日、斋日、节气、重要日**的小点则排在日期**正下方**一行，自左至右按这个次序排列，与图例一致
- 标记颜色一眼可辨：**佛教节日 金**、**斋日 蓝**、**节气 绿**、**功课 金**、**重要日 红**；图例也按「佛教节日 → 斋日 → 节气 → 功课 → 重要日」的顺序排列
- 斋日可在设置里单选一种显示：**不显示** / **朔望**（初一、十五）/ **六斋日** / **十斋日**，三种均为蓝色小点；小月无三十时，六斋以廿八、廿九补足，十斋再加廿七
- 支持**自定义农历 / 公历的重要日**（生日、纪念日等），日历上以红点与红色名称标出，日期条显示红色标签
- 选中日期下方的日信息分**三行**：第一行「佛历年份 · 公历年月日 · 昨天／今天／明天」，第二行「农历月日 · 星期」，第三行是当天的标签（佛教节日、斋日、传统节日、节气、重要日）
- 当天的公历日期显示为**金色**，提醒这一天正是今天；其他日期为墨色，背景与平日一致
- 日期信息条左右两侧各有一个 `‹` `›` 箭头：点按即切换到前一天／后一天，与在日信息区左右滑动等效
- 功课分为 **念佛 · 诵经 · 持咒 · 仪轨 · 日记** 五个标签页，内容可自行增删改
- 每项功课提供 `+1` `+10` `+100` `+1000` `+` 五个按钮：末位 `+` 按该项的默认增量增加（默认：念佛持咒 100，诵经仪轨 1）；不再单设减号，减少统一走「长按 +」
- 长按 `+` 弹出「调整当日数量」：可在**减少／增加／设为**之间切换——前两者填多少就加减多少（减到 0 为止，不会出现负数），**设为**则是直接把当天数量改成输入值（填 0 即清零）；长按 `+10` `+100` `+1000` 则是持续连加
- 点击计数数字可直接手动输入当天数量
- **点整张功课卡片**（名称、累计、目标条、空白处都算）即可进入该功课详情；只有 `+1` 等加减按钮与计数数字例外，它们照旧是计数操作
- 「显示当月累计」与「显示累计总数」都默认开启：每项功课在今日数字下方显示一行「本月 N　共 M」，**当月合计在左、累计总数在右**，随加减实时更新；两项都可在设置里单独关掉
- 前四个标签页的内容区顶部可选显示**当日计数明细**，一行列出今天记过的每一项，如「今日 南无阿弥陀佛×100；南无地藏王菩萨×1000。」，加减后即时刷新；默认关闭，可在设置里打开
- 向下滚动时，**日期信息与五个标签页一起固定在顶部**（月历滚走），随时知道在看哪一天、可以随时换标签
- 任意功课可在「功课设置」中填写**每日目标**（可选）：卡片上随即显示一条细进度条与「已完成 / 目标」，达成后数字与进度条转为金色
- 首页分三个区域，左右滑动各司其职：
  - **月历区**：右拖上一月，左拖下一月（不改选中日期）
  - **日信息区**：右拖前一天，左拖后一天
  - **内容区**：在五个标签页间左右切换；汇总视图下不响应左右滑动
- 点日期即选中该日；点日期信息区域可调出系统日期选择器（不再显示提示文字）

**详情页**
- 点功课名称进入，自上而下三段：**日信息**（公历、星期、农历、佛历与当天标签）→ **当日计数与操作按钮** → **按日／按月／按年统计**
- 计数区在今日数字下方并排显示**本月合计**与**累计总数**（本月在左、累计在右，如「本月 123 遍　累计 1234 遍」），随手加减时两者同步更新；在设置里关掉「显示当月累计」后只剩累计
- 计数区上排是一个整行大按钮 `+1`，下排依次为 `+10` `+100` `+1000` `+`（`+` 按默认增量，长按弹窗可增减或直接设定当天总量；长按 `+10` 以上则连加）
- 详情页的日信息卡片同样在左右两侧带 `‹` `›` 箭头，点按切换前后日
- 三种统计表格：**按日**（一周 7 列的整月表格）／**按月**（12 个月的表格）／**按年**（最近 6 年，3 列 2 行）
- 每格显示当日／当月／当年的累计数，底色按数量分三档加深；当前日期（月份、年份）带描边
- 顶部显示合计、记录天数（月数、年数）、日均、最高值
- 若该项设了每日目标：统计行显示「目标 X · 达标 N 天」，达标格的数字旁标一个金色 ✓
- 点日期回到该日记录；点月份看该月每日；点年份看该年各月；按年视图可用 `‹` `›` 整屏翻 6 年
- 详情页左右拖动：在**统计区**滑动切换 按日／按月／按年，在**日信息或计数区**滑动切换前后日的功课详情

**日记**
- 顶部可**选填天气**：中央台预报会播报的类型都在，常见天气排在前面——晴、多云、阴、小雨、中雨、大雨、暴雨、大暴雨、特大暴雨、阵雨、雷阵雨、小雪、中雪、大雪、暴雪、雨夹雪、冻雨、冰雹、雾、霾、浮尘、扬沙、沙尘暴、强沙尘暴、大风、台风、霜冻（三列图标，一屏选完）；也可以**自己写**（如「梅雨」「大风沙」，最多 8 字）；旁边是**地点**
- 地点有三条路：**常用地点**一键选（家、寺院、常去的道场）、**按省 / 市挑**（34 个省、近 500 个市，不必看经纬度）、**输入临时地点**（如「灵隐寺」）；用「当前位置」时会自动反查地名，坐标只存在后台，不会写成「31.23, 121.47」这样的数字
- 常用地点每一行右侧有**铅笔按钮**，在日记里点一下就能改名、改省市、设为默认或删除，不必先跳到管理页
- 选省市时可勾选「加入常用地点」，也可在已有临时地点时点「存为常用地点」；常用地点在「设置 → 常用地点」或地点面板里都能改名、改省市、删除
- 可指定一个常用地点为**默认地点**：今天及以后新的一天的日记会自动填好，手动清除后当天不再自动补；旧日期的日记不会被改写
- 地点面板会把**最近一次用过的地点**单独列在最上面（当天已改成临时地点时尤其好用），点一下即可换回
- 设置里「始终使用最近一次地点」**默认开启**：写新一天的日记时，地点自动填上次用过的那个；关掉后改用默认地点
- 工具条为四个图标：序号、圆点、图片、**插入时间**（段落直接回车即可，不再单设按钮）
- 图片按钮**轻点**从相册多选，**长按**调系统相机拍照（安卓 10 及以上拍完的照片同时留在相册，低版本只存进日记）
- 空白段落提示「记下所见、所闻、所思、所想…」，一天里的见闻、思绪都可以写进来
- 点时钟图标即新起一条带 `[21:09]` 时间戳的记录，可把一天里的事逐条记下；连点只刷新时间，不会叠加
- 支持普通段落、自动编号的有序列表、无序号圆点列表、图片
- 图片压缩后以 dataURL 文本存入 IndexedDB（不再用 Blob 与 `blob:` 地址，避免个别内核显示空白）；若某些机型上浏览器无法重新编码图片，则保留原图，绝不会存成空白图
- 如果设备上的 IndexedDB 不能用、或写入的数据下次启动读不到（部分鸿蒙兼容层会清掉），会自动降级为**把图片直接内嵌进日记记录**，与文字一起保存，重启后照样显示；此时插图改用更小的压缩尺寸，为文字留出空间
- 删除图片有三种方式：点图片**右上角的 ×**；点一下图片打开大图，再点**「删除这张图片」**；光标停在图片后的段落开头按**退格**（或选中图片按删除键）
- 回车换行自动拆分块，退格可合并回上一块

**汇总视图**
- 首页右上第一个按钮切换：记录视图 ⇄ 汇总视图
- 上半部分与记录视图完全一致：整月日历与日期条始终保留，只有下半部分的内容区在「五个标签页」与「按日滚动的汇总」之间切换
- 汇总内容顶部显示**连续功课天数**（仅前四类功课有计数才算，只有日记不算；今天还没记时由昨天起算，不会提前断签），并附累计天数与起始日期
- 汇总按日期由近及远排列，每张卡片头部附当天天气与地点，上方面板显示当天有计数的功课（如「南无阿弥陀佛×108；心经×1。」，最多 4 行），下方面板显示当天日记（最多 3 行，时间戳一并保留）
- 在汇总视图里拖动日历翻月，会自动滚到该月最近的一条记录
- 点卡片即切回五个标签页的模式并跳到那一天；点「功课」面板落在有记录的那一类，点「日记」面板落在日记页

**其他**
- 右上菜单：功课设置、佛教节日一览、传统节日一览、我的重要日、回到今天、设置
- 节日一览分「佛教节日／传统节日」两个分段，可翻年查看；传统节日含春节、元宵、龙抬头、上巳、端午、七夕、中元、中秋、重阳、寒衣、下元、腊八、小年与除夕
- 功课设置支持增删改、上下排序、恢复内置功课
- 我的重要日：添加／编辑／删除自定义重要日，可选农历或公历，列表按最近到来排序并显示还有多少天
- 设置项：佛历基准（+543／+544）、斋日显示（不显示／朔望／六斋／十斋）、佛教节日显示、传统节日显示、节气显示、我的重要日、常用地点、始终使用最近一次地点（默认开启）、显示累计总数（默认开启）、显示当月累计（默认开启）、显示当日计数明细（默认关闭）
- 数据导出／导入（JSON，含图片）、数据概况、清空数据；数据概况里「功课总计数」按 **念佛 / 诵经 / 持咒 / 仪轨 / 日记** 五类分别列出总数（念佛、持咒以遍计，诵经以部计，仪轨以遍计，日记以篇计），另附记录天数、功课条目、图片张数与最早记录
- 设置页底部为回向偈：「学佛功德殊胜行，无边胜福皆回向／普愿沉溺诸众生，速往无量光佛刹」

## 三、在安卓手机上使用

### 方式一：部署后安装为 App（推荐）

1. 把本目录下的所有文件上传到任意支持 HTTPS 的静态托管（GitHub Pages、Vercel、Netlify、对象存储、自己的服务器均可）
2. 手机用 Chrome 打开该网址
3. 右上角菜单 → **添加到主屏幕 / 安装应用**
4. 桌面会出现图标，点开后全屏运行，与原生 App 无异；断网也能用

> 必须通过 http(s) 访问才能启用离线缓存与安装。直接双击 `index.html` 以 `file://` 打开也能使用全部功能，但无法安装和离线缓存。

### 方式二：直接安装 APK（已打包好）

- 文件：`学佛日记-2.0.apk`，约 369 KB，支持 **Android 7.0 及以上**
- 传到手机后点击安装，需允许「安装未知来源应用」；首次打开若提示风险，选择「仍要安装」即可
- 内嵌的就是本目录这份 `index.html`，由 WebView 以 `https://appassets.local` 提供，因此 `localStorage` 与 IndexedDB 都能长期保存，重启应用数据不丢
- 返回键：在详情页、设置页等二级页面先退回上一层，回到首页再按一次才退出
- 「导出备份」会直接把 JSON 写进手机「下载」目录（Android 10 及以上）；导入备份、日记插图会调起系统文件选择器
- APK 申请了联网与位置权限：点「定位」时会弹出系统授权，同意后用 OpenStreetMap 反查地名；不授权也可手动填写地点
- APK 与浏览器版数据互不相通；卸载应用会一并清除数据，卸载前请先导出备份
- 若从 1.9 及更早版本升级，早先在手机上添加的日记图片可能仍是空白（旧版在部分机型上把图导出成了白图）：删掉那张图重新添加即可，新版已修正
- **鸿蒙（HarmonyOS NEXT）上的「卓易通」等安卓兼容环境**：1.13 起专门做了适配——图片不再依赖 Blob／`blob:` 地址，改为 dataURL 文本；选中的照片会先由外壳复制到应用缓存再交给网页；若该环境的 IndexedDB 存不住数据，会自动把图片内嵌进日记记录。**看日记图片不需要相册权限**（图片存在应用自己的数据里），只有在「点图片按钮挑照片」时才会调起系统选择器，那次选择本身就是一次性授权
- 安装包为自签名（非应用商店分发），以后换新版本时直接覆盖安装即可，数据保留

> 若要自己重新打包：可用 [PWABuilder](https://www.pwabuilder.com/)、Bubblewrap 或 Capacitor，把 `index.html`、`manifest.webmanifest`、`icons/` 作为静态资源即可。WebView 内 Service Worker 不生效属正常现象，不影响功能。

## 四、数据说明

- 功课、日记文字、天气与地点、目标数量、自定义重要日保存在浏览器 `localStorage`（键名 `xuefo.diary.v1`）
- 日记图片保存在 IndexedDB（库名 `xuefo-img`，值为 dataURL 文本）；若该设备 IndexedDB 不可用或不持久，则直接内嵌在 `xuefo.diary.v1` 的日记记录里（`b.x` 字段）
- 常用地点（名称、省市、可选经纬度）与默认地点也存在同一条数据里，随备份一起导出／导入
- 省市列表内置在 `index.html` 中（34 个省级、近 500 个市级），选省市不需要联网
- 反向地理编码（坐标 → 地名）使用 OpenStreetMap Nominatim 的公开接口；无网络或超时会保留「当前位置」，可再按省市选择或手动填写
- 所有数据只在本机，不上传任何服务器；清除浏览器数据或卸载应用会一并清除
- 自定义重要日随同一条数据保存，导出备份会一并带上；农历条目每年按农历月日重算，闰月不另计
- 建议定期用「设置 → 导出备份」保存一份 JSON 到网盘

## 五、历法口径

- 农历、节气由 `lunar-javascript`（6tail）推算，覆盖 1900–2100 年
- 佛历采用「公历年 + 基准」，默认 +543（佛历元年为公元前 544 年，与泰国历及汉传常用说法一致），可在设置中改为 +544
- 朔望日：农历初一（朔）、十五（望）
- 六斋日：农历初八、十四、十五、廿三、廿九、三十；**小月无三十，以廿八、廿九代之**，仍为六日
- 十斋日：大月为初一、初八、十四、十五、十八、廿三、廿四、廿八、廿九、三十；小月无三十，则为初一、初八、十四、十五、十八、廿三、廿四、**廿七**、廿八、廿九，十日不缺
- 三者互斥，一次只在日历上标一类
- 「有功课」只认前四类功课的计数；日记不参与日历标记与连续天数，但仍完整保留在汇总列表里
- 闰月按当月实际天数计算，不另作增减
- 佛教节日按农历月日计算，闰月不计。诸佛菩萨纪念日各寺所用历法略有出入，此表依通行之说；如需增改，编辑 `index.html` 中的 `FESTIVALS` 常量即可
